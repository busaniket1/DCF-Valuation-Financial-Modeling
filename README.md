# DCF-Valuation-Financial-Modeling-Excel
Project Overview

Built an Excel-based Discounted Cash Flow (DCF) valuation model to estimate the intrinsic value of a company using historical financial data and hypothetical forecast assumptions.

Key Features
Historical financial analysis and revenue forecasting
Base, Best & Worst Case scenario analysis
FCFF forecasting
WACC calculation using CAPM and cost of debt
Terminal Value using Gordon Growth Method
Enterprise Value → Equity Value → Fair Value per Share
WACC vs Terminal Growth sensitivity analysis
NPV & IRR cross-check
Model validation checks
Key Finding

Under the Base Case assumptions, the model estimates a fair value of approximately ₹1,777 per share, compared with a market price of approximately ₹4,000, indicating a significant difference between the model-derived intrinsic value and market valuation.

Skills Demonstrated

DCF | FCFF | WACC | CAPM | NPV | IRR | Financial Forecasting | Scenario Analysis | Sensitivity Analysis | Excel
